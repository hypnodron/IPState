## 🌍 IP State 1.0

**Your public IP, at a glance.** IP State's first stable release keeps your VPN's exit IP, location, and connection status in the macOS menu bar.

### ✨ What's included

- Show your public IP, country flag, country code, city, or a combination. Reorder items and limit long names.
- Track IPv4 and IPv6 independently, with automatic selection for the menu bar.
- Check on network changes and wake, plus a configurable interval from five seconds to 15 minutes.
- Get IP-change alerts with the full address and available location. Enable optional connection loss and recovery alerts.
- Reuse remembered IP locations and opt into local history with a configurable limit.
- Check for signed app updates manually or daily. Preview releases are optional; installation requires confirmation.

### ⬇️ Install or update

Download **IPState-1.0.0-universal-macos.zip**, extract it, and move **IP State.app** into Applications.
The universal app supports Apple silicon and Intel and requires macOS 14 or later.

Already on 0.11.0? Choose **Check for Updates…** in the app menu.
Earlier versions need one manual installation to enable app updates.
Your existing IP State settings remain intact.

### ℹ️ First launch

This release is ad-hoc signed and **not notarized by Apple**. macOS may block its first launch.
See [Apple's instructions for opening an unidentified developer's app](https://support.apple.com/guide/mac-help/mh40617/mac).
The source is available if you prefer to build it yourself.

The `.sha256` file records the ZIP's SHA-256 checksum.
Sparkle verifies the update archive's signature before installation.
