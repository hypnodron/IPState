# Social preview

[social-preview.png](social-preview.png) is the selected GitHub social preview.
It is an opaque 1280 × 640 PNG under GitHub's 1 MB limit.
The illustrated menu bar shows `192.168.6.7` and `16:20`.

## Use on GitHub

Committing the image does not configure the repository's social preview.
Upload `social-preview.png` in **Settings → General → Social preview → Edit → Upload an image**.
See [GitHub's instructions](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview).

## Artwork

Generated with the built-in image_gen tool on November 14, 2026, using the IP State globe-and-beacon identity.
The export was resized with macOS sips. Nonessential metadata was removed without changing compressed pixel data.
The IP address is an illustrative local example, not a live lookup.
