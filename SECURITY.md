# Security reports

Use the repository's **Security → Report a vulnerability** option when private vulnerability reporting is available.
If it is unavailable, open an issue asking for a private reporting channel without disclosing exploit details or personal data.

Do not include public IP history, credentials, signing files, or private network details in a public report.
For ordinary bugs, use the bug report template with example addresses.

IP State does not change network configuration or operate a server.
Its network behavior and local storage are described in [the privacy document](docs/privacy.md).
